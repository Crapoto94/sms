Passerelles

Chaque passerelle en ligne reçoit en priorité les envois vers les numéros qu'elle a déjà contactés récemment, puis se voit attribuer les nouveaux numéros par ordre de charge croissante, dans la limite du quota ci-dessous (protection contre le blocage anti-spam opérateur — les forfaits mobile grand public limitent en général les SMS illimités à ~200 destinataires distincts par mois).

Synchronisation de carnets

Synchronisez des carnets d'adresses depuis une autre instance de la passerelle SMS. Entrez l'URL (port API) et une clé « web » de l'autre instance, parcourez ses carnets puis cochez ceux à synchroniser. Les carnets synchronisés ne sont visibles que par les administrateurs et sont mis à jour automatiquement toutes les heures.

Mail → SMS

Les boîtes configurées sont relevées en IMAP. Le sujet de l'e-mail devient le contenu du SMS, le corps contient les destinataires : des numéros de téléphone et/ou le nom d'un carnet d'adresses (ligne « carnet : nom », « #nom » ou le nom exact du carnet). Les pièces jointes sont conservées et un lien public est ajouté au SMS. Un compte-rendu est renvoyé à l'expéditeur après le délai configuré.

SMS externe (Frizbi)

Choisissez le canal d'envoi des SMS : les passerelles internes (téléphones), l'API externe Frizbi, ou les deux. En mode « Les deux », Frizbi n'est utilisé que si l'envoi dépasse le seuil ci-dessous ; sous ce seuil, l'envoi passe par les passerelles. La vérification de flotte reste toujours envoyée en interne (elle attend une réponse SMS, impossible avec le sender ID alphanumérique de Frizbi).
